# 提醒闹钟(Notice)

一个 Android 闹钟应用。核心特性(按需求实现):

- 设置提醒时间(时:分),可选每周重复的星期
- **铃声设置**:每个闹钟可选系统铃声 / 本地音乐文件 / 无声(仅震动),默认系统闹钟铃声
- 到点响铃:全屏提醒界面 + 通知栏,循环播放所选铃声并震动
- **「停止铃声」和「关闭闹钟」是两个不同的操作**:
  - 响铃全屏页和通知栏上只有「停止铃声」;**关闭本次闹钟只能进入 App,在闹钟列表顶部的提醒条上操作**
  - 点「停止铃声」:只静音当前铃声,本次闹钟仍处于激活状态
  - 每隔 **X 分钟**(每个闹钟可单独设置,默认 5 分钟,支持 1~720)自动再次响铃
  - 反复「停止铃声」会反复再响,**直到在 App 里关闭本次闹钟为止**
- 关闭本次闹钟后:一次性闹钟自动停用,每周重复的闹钟自动排到下一次
- 手机重启后自动恢复所有闹钟;若关机时有未关闭的闹钟,开机后继续提醒
- **电池优化白名单引导页**:首次启动自动出现(可跳过),也可从主界面菜单进入;一键跳转系统白名单设置,并附国产 ROM 自启动/省电策略设置指引

## 构建

要求:JDK 17+,Android SDK(platform 33、build-tools 33.0.1)。
`local.properties` 中 `sdk.dir` 指向你的 SDK 目录。

```bash
./gradlew :app:assembleDebug
# 产物: app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

也可以直接用 Android Studio 打开本目录构建运行。

## 使用说明

1. 首次启动会依次引导:「通知」权限 →「闹钟和提醒」(精确闹钟)权限 → 电池优化白名单(息屏准点响铃的关键)——都建议允许;电池优化引导页之后可从主界面菜单再次进入
2. 点右下角 **+** 添加闹钟:选时间、标签、**铃声**(系统铃声/本地音乐/无声)、重复星期、**再次响铃间隔(分钟)**
3. 到点后:
   - 全屏界面和通知栏只有「**停止铃声**」:安静 X 分钟后自动再响
   - 要结束本次闹钟,点通知或打开 App,在**闹钟列表顶部的橙色提醒条**上点「**关闭本次闹钟**」
   - 提醒条会显示当前状态(正在响铃 / 已停止铃声·约 N 分钟后再次响铃)
4. 长按列表项可删除闹钟

## 技术要点

| 模块 | 说明 |
|---|---|
| `AlarmScheduler` | `AlarmManager.setExactAndAllowWhileIdle` 精确触发;重响也走精确闹钟 |
| `RingService` | 前台服务,`MediaPlayer`(USAGE_ALARM,循环) + 震动;状态持久化,进程被杀后可恢复 |
| `Notifier` | 响铃通知(高优先级、全屏 Intent、双按钮)与待重响通知(低优先级) |
| `AlarmStore` | SharedPreferences + JSON 持久化;记录"激活中的闹钟"以便重启恢复 |
| `BootReceiver` | 开机/时间变更/应用更新后重排所有闹钟;未关闭的闹钟继续响 |

## 已知限制

- 同一时刻只支持一个正在响铃的闹钟(新闹钟触发会接替旧的)
- 关机期间错过的历史响铃不补响,重启后从下一次开始(未关闭的闹钟除外,会立即恢复提醒)
